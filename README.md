# KINGSAN-RUN (킹산런)

쿠키런 오븐브레이크 스타일의 픽셀 러너. `assets/` 의 재래시장 에셋으로 만든
320×180 원본 해상도 웹 게임이다. 빌드 도구·의존성 없음.

## 실행

```bash
python3 tools/serve.py
```

띄우면 접속 주소를 찍어 준다.

```
이 컴퓨터   http://localhost:5177
핸드폰      http://192.168.x.x:5177      <- 같은 와이파이에서 이 주소
```

핸드폰 브라우저에 그 주소를 입력하면 바로 플레이할 수 있다.
(파일을 고치면 새로고침만으로 반영되도록 `Cache-Control: no-store` 를 붙여 둔다.
기본 `python3 -m http.server` 로 띄우면 브라우저가 옛 파일을 계속 쓰는 일이 잦다.)

`index.html` 을 그냥 더블클릭해도 열린다 — ES 모듈을 쓰지 않아 `file://` 에서도 동작한다.

## 조작

### 키보드

| | 키 |
|---|---|
| 점프 / 2단 점프 | `Space` `↑` `W` |
| 슬라이드 | `↓` `S` `Shift` (누르는 동안) |
| 일시정지 | `P` `Esc` |
| 다시 시작 | `R` |
| 음악 켜기/끄기 | `M` |
| 캐릭터 바꾸기 | `←` `→` (타이틀에서) |

점프 버튼을 짧게 누르면 낮게, 길게 누르면 높게 뛴다.
공중에서 한 번 더 누르면 회전하며 2단 점프.

### 핸드폰 (터치)

터치 기기로 접속하면 **온스크린 버튼이 자동으로 나타난다**. 키보드 없이 전부 조작된다.

- **점프** 버튼 — 공중에서 한 번 더 누르면 2단 점프. 게임 화면 아무 곳을 눌러도 점프한다
- **슬라이드** 버튼 — 누르고 있는 동안 유지
- 두 버튼을 **동시에** 눌러도 된다 (슬라이드 중 점프)
- 상단 작은 버튼 — `❚❚` 일시정지 · `♪` 음악 · `⛶` 전체화면
  (전체화면은 지원하지 않는 브라우저에서는 자동으로 숨는다)
- 타이틀·게임오버 화면은 아무 곳이나 눌러 시작·재시작

화면 방향에 따라 배치가 바뀐다.

| | 배치 |
|---|---|
| **세로** | 게임은 위, 버튼은 화면 아래(엄지 닿는 곳)에 큼직하게 |
| **가로** | 게임이 화면을 꽉 채우고, 버튼은 양쪽 아래 구석에 반투명 원형으로 |

가로가 화면을 더 크게 쓰므로, 세로일 때는 안내 문구가 뜬다.
버튼이 캐릭터나 다가오는 장애물을 가리지 않도록 구석에 배치했다.

데스크톱에서는 버튼이 나오지 않는다. 브라우저에서 확인하고 싶으면
주소 끝에 `?pad=1` 을 붙이면 강제로 표시된다.

## 규칙

- **할머니**, **배달 스쿠터** → 점프로 넘는다
- **시장 천막** → 슬라이드로 지나간다 (점프로는 넘을 수 없다)
- **배추 10점 / 마늘 25점 / 고추 40점** — 연속으로 먹으면 8개마다 배수가 오른다 (최대 ×4)
- **황금 배추** → 5초간 *골든 러시*: 무적 + 자석 + 점수 2배, 장애물은 부딪히면 부서진다
- 하트 3개. 부딪히면 하나 줄고 약 1.3초 무적. 0이 되면 끝
- 달릴수록 빨라진다 (2.4 → 5.4 px/frame)

## 캐릭터

타이틀 화면에서 ◀ ▶ 로 고른다. 고른 캐릭터는 다음에 열 때도 기억된다.

| id | 이름 | 특징 |
|---|---|---|
| `kingsan` | 킹산이 | 검은 단발 · 초록 선글라스 · 남색 재킷 |
| `hosanna` | 호산나 | SF 야구모자 · 긴 검은 머리 · 흰 셔츠 · 청바지 |
| `goguma` | 고구마 | 긴 검은 머리 · 둥근 금테 안경 · 남색 가디건 · 교복 |
| `cookie` | 용감한쿠키 | 진저브레드 쿠키 · 아이싱 장식 · 사탕 지팡이 |
| `kimchi` | 김치맨 | 원본 에셋에 들어 있던 주황 정장 |

`SKINS` 의 **첫 번째** 항목이 기본 캐릭터다.

소품(사탕 지팡이)은 손 픽셀이 아니라 **머리 기준 고정 위치**에 그린다.
손은 8프레임 중 3개에서만 몸 밖으로 보여서, 손에 붙이면 프레임마다 튀어 보인다.
위치·길이는 레시피의 `cane` 값으로 조절한다.

### 사진에서 만드는 방법

원본 `player_run` / `player_jump` 의 포즈와 타이밍을 그대로 쓰고 **색과 머리·모자·안경만
바꾸는** 방식이다. 실제 폰트를 작게 줄이면 뭉개지는 것처럼, 32px 짜리 사람을 처음부터
그리면 애니메이션 품질을 맞추기 어렵기 때문이다.

```bash
python3 tools/make_characters.py            # 전부 다시 생성
python3 tools/make_characters.py hosanna    # 하나만
```

[`tools/make_characters.py`](tools/make_characters.py) 의 `CHARACTERS` 에 한 항목
추가하고, [`src/config.js`](src/config.js) 의 `SKINS` 에 등록하면 끝이다.

```python
'chulsoo': {
    'name': '철수', 'hl': '#8899cc',
    'hair': 'keep',                      # 'keep' 또는 자를 행수(음수면 더 짧게)
    'hair_col': ('#26262f', '#111117'),
    'glasses': ('#b8923a', 'clear'),     # (테, 렌즈) / 렌즈 'clear'=비침 / None=안경 없음
    'cap': ('#6e4a3c', '#ee6a1c'),       # (크라운, 챔) 또는 None
    'top':    ('#3f5490', '#2a3a68'),    # 상의 (밝은면, 어두운면)
    'bottom': ('#7d3446', '#57202f'),    # 하의
    'shirt': '#eef2f8', 'placket': '#b9432f', 'shoe': '#eceff5',
    # 옵션: 손에 드는 소품 (머리 중심 기준 상대 좌표)
    'cane': {'dx': -11, 'dy': 5, 'len': 13, 'hook': 2, 'w': 2,
             'red': '#d8342e', 'cream': '#f4f1e8'},
    # 옵션: 쿠키 캐릭터 — 사람 머리를 동그란 쿠키 머리로 바꾼다
    'cookie': True, 'head_r': 6, 'head_dx': -2,
    'icing': '#f4f1e8', 'eye': '#33180c', 'outline': '#3a1a0c',
},
```

동작 방식:

- 원본의 **고글 위치**를 얼굴 기준점으로 삼아, 프레임마다 머리·이마·눈 위치를 찾는다
- 흰색 픽셀은 **렌즈 / 신발 / 셔츠**로 자동 분류한다 (원본이 세 곳에 같은 색을 쓴다)
- 상의/하의는 몸통 높이의 42% 지점을 허리선으로 잡아 나눈다
- 모자를 지정하면 눈높이 위쪽을 크라운으로 덮고, 얼굴 앞으로 챔을 뻗는다
- 마지막에 윤곽선을 다시 그린다

### 시트 규격 (직접 그릴 때)

```
<이름>_run.png    128×64   32×32 프레임 8장 (가로 4 × 세로 2, 왼→오, 위→아래)
<이름>_jump.png   192×64   32×64 프레임 6장 (가로 6 × 세로 1)
                           0 웅크림 → 1 상승 → 2 최고점 → 3 하강 → 4 착지 → 5 복귀
```

- 캐릭터는 **오른쪽을 보고** 있어야 한다. 배경은 투명, 윤곽선은 1px
- `jumpFeet[i]` 는 i번째 점프 프레임에서 **발바닥이 있는 셀 내부 y**
- `slideFrame` 은 슬라이드 자세로 쓸 점프 프레임 번호 (기본 4 = 웅크린 착지 자세)

파일명만 맞춰 `assets/player2_run.png` + `assets/player2_jump.png` 로 넣으면
`SKINS` 에 등록하지 않아도 자동으로 목록에 붙는다 (`player2`, `player3`).
비어 있는 슬롯 때문에 콘솔에 404 가 몇 개 찍히는데 정상이다.

## 간판 글자

상점 간판의 한글은 코드로 다시 그린다. 실제 폰트를 9px 로 래스터화하면
획이 뭉개져 못 읽으므로, 원본 에셋에 있던 글자를 픽셀 단위로 뜯어
같은 규칙(셀 9x9, 획 1px)으로 만든 전용 픽셀 글립을 쓴다.

```bash
python3 tools/retext_buildings.py
```

| 파일 | 바뀐 글자 |
|---|---|
| `building_01` | 우리재래시장 → **도깨비시장** |
| `building_02` | 제일상회 → **와플대학** |
| `building_03` | 스타노래방 → **똥냄새노래방** (앞 3자 크림 / 뒤 3자 노랑) |
| `building_03` | 행운미용실 → **최헤어필** |
| `building_04` | 싱싱야채·청과 → **ㅇㅇㅅㅋㄹ** (파랑·초록·빨강) |
| `building_05` | 엄마손만두 → **맛깔 ● 식당** |

- 원본 5장은 `assets/orig/` 에 보관된다. 스크립트는 **항상 원본에서 다시 시작**하므로
  글자만 바꿔서 몇 번이든 돌릴 수 있다
- `building_05` 의 빨간 원은 원래 안에 「손」이 들어 있던 로고인데,
  글자를 지워 순수한 원으로 두고 그 좌우에 **맛깔 / 식당** 을 나눠 넣었다
- `building_03` 세로 「노래방」 간판, `building_01` 아래쪽 현수막,
  `building_04` 의 「도·소매 123-4567」 은 요청에 없어 그대로 두었다

### 다른 문구로 바꾸기

1. [`tools/hangul9.py`](tools/hangul9.py) 의 `G9` 에 필요한 음절을 9줄 문자열로 추가
   (`#` = 칠함, `.` = 빔). 낱자는 7x6 짜리 `G6` 에 추가
2. [`tools/retext_buildings.py`](tools/retext_buildings.py) 의 해당 `job_*()` 에서
   `text` 를 바꾼다. 글자 수가 달라지면 `layout()` 이 원래 영역 가운데로 다시 배치한다
3. 스크립트를 다시 실행

배경 복원 방식은 간판마다 다르다 — 하늘 위에 뜬 글자는 투명, 세로 줄무늬 간판은
깨끗한 행 복사, 벽돌 벽은 y 주기 4 로 복사, 단색 명판은 그냥 칠하기.
`ASSET_VERSION` 을 올리면 브라우저가 새 이미지를 다시 받는다.

## 튜닝

숫자는 전부 [`src/config.js`](src/config.js) 한 곳에 모여 있다. 자주 만지는 것들:

| 상수 | 뜻 |
|---|---|
| `RUN_ANIM_RATE` | 달리기 **모션**만 빠르게/느리게 (이동 속도와 무관). `0.5` = 절반 |
| `SPEED_BASE` `SPEED_MAX` `SPEED_RAMP` | 스크롤 속도와 가속 |
| `JUMP_V` `JUMP2_V` `GRAVITY` | 점프 높이 (`JUMP_V²/(2·GRAVITY)` ≈ 최고점) |
| `MAX_HP` `HURT_FRAMES` | 체력, 피격 후 무적 시간 |
| `SLIDE_MIN` `SLIDE_MAX` | 슬라이드 최소·최대 유지 프레임 |
| `GOLD_FRAMES` `MAGNET_R` | 골든 러시 길이와 자석 반경 |
| `AWNING_BOTTOM` | 천막 아래 통과 높이 |
| `ASSET_VERSION` | 에셋을 고쳤는데 브라우저가 옛 파일을 쓸 때 올린다 |

## 구조

```
index.html          화면 골격 + 오버레이 UI (한글 텍스트는 DOM 쪽)
style.css           정수 배율 스케일링, 패널/버튼
src/config.js       모든 튜닝값, 스킨 정의, 팔레트
src/font.js         5×7 픽셀 폰트 (캔버스 HUD 숫자용)
src/assets.js       이미지 프리로드 + 스킨 슬롯 자동 탐지
src/audio.js        WebAudio 로 합성하는 효과음 + 배경 루프
src/input.js        키보드 / 마우스 / 터치 버튼 (멀티터치)
src/background.js   하늘·원경빌딩·상점·바닥 4겹 패럴랙스
src/player.js       달리기/점프/2단점프/슬라이드/피격 상태
src/entities.js     장애물, 아이템, 이펙트, 패턴 스포너
src/hud.js          하트, 점수, 콤보, 골든 게이지
src/game.js         메인 루프, 상태 전환, DOM 연결
tools/serve.py            개발용 서버 (랜 접속 + 캐시 끄기)
tools/pngio.py            의존성 없는 PNG 읽기/쓰기
tools/hangul9.py          간판용 9x9 한글 픽셀 글립
tools/retext_buildings.py 상점 간판 글자 교체
tools/make_characters.py  플레이어 스프라이트 생성
tools/make_title.py       타이틀 로고 생성
```

브라우저 콘솔에서 `KingsanRun` 으로 상태를 들여다보고 프레임을 직접 돌릴 수 있다:

```js
KingsanRun.start()        // 바로 시작
KingsanRun.advance(120)   // 120프레임 진행 후 상태 반환
KingsanRun.g.player       // 플레이어 내부 상태
KingsanRun.setSkin(1)     // 스킨 바꾸기
```
